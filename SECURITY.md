# Security Policy

This project follows [GitHub's recommended security policy format](https://docs.github.com/en/code-security/getting-started/adding-a-security-policy-to-your-repository).

## Supported Versions

Only the most recent minor release of `lcobucci/clock` receives security updates. Older versions may not be maintained.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it as soon as possible by emailing [lcobucci@gmail.com](mailto:lcobucci@gmail.com) or opening an issue on our [GitHub issue tracker](https://github.com/lcobucci/clock/issues).

We will respond promptly and keep you informed of the progress.
